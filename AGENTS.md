# Shared project guidance

The project has a React/TypeScript app in `frontend/` and a planned Express/TypeScript backend in `backend/`. Read `mvp.docx` for product requirements. Follow the `AGENTS.md` inside the relevant folder for implementation guidance.

For any API or backend work, read the project-root `API_CONTRACT.md`. It is the shared agreement for endpoints, data shapes, authentication, permissions, and errors. Keep the contract, backend, and frontend API client/types aligned when changing API behavior.

Only when the user asks for coding work, each agent that changes frontend or backend code must append a dated entry to the project-root `WORK_LOG.md`. Record the coding task, code files changed, and checks run; distinguish planned work from completed work. Do not log planning discussions or documentation-only changes.

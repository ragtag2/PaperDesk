# Backend guidance

Apply this guidance to backend work in `backend/`. The planned stack is Express with TypeScript and MongoDB. Read the project-root `mvp.docx` for product requirements and the project-root `API_CONTRACT.md` before implementing or changing routes, data shapes, authentication, or permissions.

Treat `API_CONTRACT.md` as the frontend/backend agreement. If a backend requirement changes that agreement, update the contract and coordinate the corresponding frontend API client/types change. Do not silently change response shapes or access rules.

Follow the shared coding-log rule in the project-root `AGENTS.md`. Add further backend implementation guidance here when the backend prompts are supplied.
